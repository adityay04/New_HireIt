# HireIt 🚀

HireIt is a modern AI-powered career platform built to help users create professional resumes, generate portfolios, improve ATS scores, and use AI tools for career growth.

The project combines:

- Resume Builder
- AI Resume Enhancement
- Portfolio Generator
- ATS Optimization
- Shareable Resume Links
- Multiple Resume Templates
- Responsive Dashboard
- Dark / Light Theme System

into one unified platform.

---

# 🌟 Why HireIt?

Most resume builders today are:

- Static
- Generic
- Not ATS optimized
- Limited in customization
- Expensive
- Lack AI assistance
- Have outdated UI/UX
- Don't provide portfolio generation

HireIt solves these problems using AI + modern full stack technologies.
